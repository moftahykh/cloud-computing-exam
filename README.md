# Cloud Computing Exam Simulator ??

An advanced, fully client-side exam simulation platform designed for University Cloud Computing students.

## Features ?
- **1900+ Questions:** A massive database covering 9 chapters.
- **Two Study Banks:**
  - **Curated Bank (440 Qs):** High-yield, instructor-style tricky questions.
  - **Comprehensive Bank (1,465 Qs):** Complete coverage.
- **Dynamic Exam Modes:** Study Mode and Mock Exam Mode.
- **Difficulty Badges:** Automatically generated difficulty tags.
- **Offline Capable:** Works fully offline after the first visit.
