CLOUDQ — INFINITYFREE UPLOAD
============================

This is a complete static website. No database, PHP, Node.js, or account setup is required.

UPLOAD
1. Open InfinityFree File Manager (or connect with FTP).
2. Open the htdocs directory.
3. Upload the CONTENTS of this folder into htdocs:
   - index.html
   - 404.html
   - manifest.webmanifest
   - service-worker.js
   - assets/ folder
   - data/ folder
4. Visit your InfinityFree domain.

IMPORTANT
- Keep the folder structure unchanged.
- If an old version was uploaded before, clear the browser cache or unregister its service worker.
- All progress and answers are stored locally in each student's browser. Nothing is sent to a server.
- The website contains both complete banks:
  Curated: 440 questions
  Comprehensive: 1,905 questions
  Total records: 2,520

FILES TO EDIT LATER
- Visual styling: assets/styles.css
- Application behavior: assets/app.js
- Question data: data/questions.json
